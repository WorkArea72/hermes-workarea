Política de privacidad

Hermes-workarea · Última actualización: 3 de octubre de 2026

Quién usa la aplicación

Hermes-workarea es una aplicación de uso personal. Su único usuario es su propietario y solo accede a la cuenta de Google de esa persona.

Datos de Google a los que accede

Con el consentimiento expreso del propietario, la aplicación solicita estos permisos de Google:

  • Gmail: leer, buscar, enviar y responder correos, y gestionar etiquetas.
  • Google Calendar: consultar, crear y eliminar eventos.
  • Google Tasks: consultar tareas.
  • Google Drive, Docs y Sheets: buscar, leer, crear, compartir o eliminar archivos, siempre a petición del propietario.
  • Contactos: consultar contactos.

Cómo se usan los datos

  • Solo para responder a las peticiones que hace el propietario, por ejemplo "¿qué tengo mañana?" o "añade un aviso el día 3".
  • No se venden, no se ceden a terceros y no se usan con fines publicitarios.
  • No se usan para entrenar modelos de inteligencia artificial generalistas.
  • Para generar las respuestas, el texto de la petición y los datos imprescindibles se envían a un proveedor de modelos de lenguaje, sin almacenarlos con otros fines.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Almacenamiento

El token de acceso de OAuth y el historial de conversación se guardan en un servidor privado controlado por el propietario. No hay ninguna base de datos compartida con terceros.

Revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
